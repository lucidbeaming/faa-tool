# Who made FAA-TOOL — Joshua Curry

Source: https://joshuacurry.dev (read 2026-11-14). Link: https://joshuacurry.dev

- Joshua Curry: "Full stack web developer with a focus on AI, mobile, and accessibility."
- Projects span 2010 to 2026.
- Works in TypeScript, JavaScript, React, React Native, Next.js, SvelteKit, Node.js, Python, PHP and C++, plus databases like PostgreSQL and MongoDB.
- Accessibility work: WCAG, screen readers, keyboard navigation.
- Has done work for or with Walmart, Berliner Zeitung, Chegg (Mathway), Oath (Yahoo!), DreamFactory, Deed and Blackbaud.
- Built Open Call Manager, a SaaS for art open calls: "Four months from research to MVP, system-designed and run by me, and built with AI."
- AI work: an AI agent observability tool for Walmart; ChatJC, a chatbot about his work built with LangChain and Mistral AI; open-source Mistral tools (alt-tagger, generatejsonld); an Art Review Generator (GPT-2 trained on art reviews).
- Won the Seeed Studio Vision AI challenge with a custom YOLOv5 model on a tiny vision module.
- Artist too: "Embers", a breath-powered installation of 1,250 LEDs shown at the SubZERO festival and Kaleid Gallery; vid2midi, a tool that turns video into music.
- FAA-TOOL itself is a SvelteKit app using Mistral AI.
